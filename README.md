# FutebolBR — Inteligência de Dados no Futebol Brasileiro

## Sobre o projeto

O FutebolBR é um projeto acadêmico desenvolvido no curso de Sistemas de Informação, com o objetivo de reunir, organizar e analisar indicadores de 20 clubes do futebol brasileiro.

O trabalho integra ferramentas de Business Intelligence e Sistemas de Informação Geográfica para apresentar informações sobre os clubes de maneira visual, interativa e organizada.

## Objetivos

- Analisar indicadores dos principais clubes do futebol brasileiro.
- Comparar tamanho das torcidas e quantidade de sócios-torcedores.
- Explorar títulos nacionais e internacionais.
- Comparar a capacidade dos estádios.
- Analisar a década de fundação e os modelos de gestão dos clubes.
- Representar geograficamente os Centros de Treinamento e estádios.

## Tecnologias utilizadas

- **HTML5:** estruturação do site.
- **CSS3:** estilização e responsividade.
- **JavaScript:** funcionalidades e interatividade.
- **ArcGIS:** visualização e análise geográfica.
- **Microsoft Power BI:** criação do painel de indicadores.
